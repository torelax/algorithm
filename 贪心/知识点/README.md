# 贪心算法 Greedy Algorithm

## 基本思想

贪心算法在每步决策时都选择当前看起来最优的选择，期望通过局部最优来达到全局最优。

**适用条件：**
1. **贪心选择性质**：每步的贪心选择都是安全的
2. **最优子结构**：问题的最优解包含子问题的最优解

## 经典应用

### 区间调度
按结束时间排序，每次选择结束时间最早且与已选区间不冲突的区间：
```python
def intervalSchedule(intervals):
    intervals.sort(key=lambda x: x[1])
    count, end = 0, float('-inf')
    for start, finish in intervals:
        if start >= end:
            count += 1
            end = finish
    return count
```

### 霍夫曼编码
用最小堆每次合并两个最小权重的节点，构建最优前缀编码树。

### 分糖果 / 分配问题
将较小的需求与较小的满足量配对，可以满足最多的人。

## 与动态规划的区别

| | 贪心 | 动态规划 |
|--|------|---------|
| 决策方式 | 只考虑当前最优 | 考虑所有子问题 |
| 时间复杂度 | 通常更快 | 通常较慢 |
| 适用性 | 更严格 | 更广泛 |
| 能否回退 | 不能 | 通过备忘录复用 |

## 验证贪心正确性

证明贪心算法正确的常用方法：
- **交换论证法**：假设存在最优解不使用贪心策略，通过交换操作证明可以转化为贪心解且不变差
