# 算法知识库

本项目按算法与数据结构知识点分类，每个类别包含**知识点**（原理讲解与模板代码）和**例题**（OJ 题目题解）。

## 目录结构

| 目录 | 说明 |
|------|------|
| [动态规划/](动态规划/) | 动态规划算法，含备忘录、背包、序列 DP 等 |
| [字符串/](字符串/) | 字符串算法，含 KMP、滑动窗口、回文等 |
| [图论/](图论/) | 图与树的算法，含 DFS、BFS、最短路、树形 DP 等 |
| [排序/](排序/) | 排序算法，含快排、归并、堆排及二分查找 |
| [数学/](数学/) | 数论、组合数学、进制转换、高精度等 |
| [搜索与回溯/](搜索与回溯/) | 深度优先搜索、广度优先搜索、回溯剪枝等 |
| [贪心/](贪心/) | 贪心算法，含区间调度、分配问题等 |
| [数据结构/](数据结构/) | 栈、队列、链表、堆、并查集等数据结构 |
| [位运算/](位运算/) | 位运算技巧与应用 |
| [refs/](refs/) | 参考资源（竞赛题目、课程作业、实验报告等） |

## 类别结构

每个知识点目录均包含：

```
<知识点>/
├── 知识点/    # 算法原理、模板代码、笔记
└── 例题/      # LeetCode / UVa / POJ 等 OJ 题解
```

## 参考资源（refs/）

无法按知识点分类的内容统一放入 `refs/` 目录：

- `refs/ACM/` — ACM-ICPC 校内选拔赛题目与题解
- `refs/Algotest/` — 算法课程实验与周练习
- `refs/DataG/` — 数据结构课程作业
- `refs/POJ/` — POJ 在线评测题解
- `refs/程序设计实践/` — 程序设计实践课程习题
- `refs/test/` — 临时测试与草稿文件
- `refs/面试题/` — 面试题目
