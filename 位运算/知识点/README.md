# 位运算 Bit Manipulation

## 基本位运算

| 运算 | 符号 | 示例 | 说明 |
|------|------|------|------|
| 与 AND | `&` | `5 & 3 = 1` | 都为1才为1 |
| 或 OR | `\|` | `5 \| 3 = 7` | 有1则为1 |
| 异或 XOR | `^` | `5 ^ 3 = 6` | 不同为1 |
| 非 NOT | `~` | `~5 = -6` | 取反 |
| 左移 | `<<` | `5 << 1 = 10` | 乘2 |
| 右移 | `>>` | `5 >> 1 = 2` | 除2 |

## 常用技巧

```cpp
// 判断第 i 位是否为 1
(n >> i) & 1

// 将第 i 位置为 1
n | (1 << i)

// 将第 i 位置为 0
n & ~(1 << i)

// 翻转第 i 位
n ^ (1 << i)

// 去掉最低位的 1
n & (n - 1)

// 获取最低位的 1
n & (-n)

// 判断是否是 2 的幂
n > 0 && (n & (n - 1)) == 0
```

## 异或的性质

- `a ^ a = 0`（自己与自己异或为0）
- `a ^ 0 = a`（与0异或不变）
- `a ^ b = b ^ a`（交换律）
- `(a ^ b) ^ c = a ^ (b ^ c)`（结合律）

**应用**：找出数组中只出现一次的数（其余均出现两次），只需将所有数异或即可。

## 子集枚举

```cpp
// 枚举 n 的所有子集
for (int mask = 0; mask < (1 << n); mask++) {
    // mask 的每一位代表是否选取对应元素
}
```
